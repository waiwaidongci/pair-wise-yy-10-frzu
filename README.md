# AeroStation 三维产品配置器

基于 Vue 3、TypeScript、Vite、Three.js、TresJS、Pinia、Tailwind CSS、Headless UI 和 Vue Router。

## 运行

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm build
```

## 配置修订 × 库存批次 × 报价锁定单 联动

代码按「数据 / 判定 / 页面」三处分离：

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 数据 | `src/data/catalog.ts` | 选项目录、SKU、默认配置 |
| 数据 | `src/data/mockServer.ts` | 版本化修订 / 库存批次 / 依赖规则 / 锁定单的 mock 服务端（localStorage 持久化） |
| 判定 | `src/domain/configLogic.ts` | 三方字段合并、依赖规则、定向失效、报价计算（纯函数） |
| 编排 | `src/stores/configurator.ts` | 冻结、操作号日志、重连合并、裁决、重算、锁定单联动 |
| 页面 | `src/pages/*`、`src/components/*` | 配置页、修订列表、三维预览、分享页 |

### 协作与修订规则

- 顾客与门店各开一份配置（角色切换）；每次打开先**冻结基础价、依赖规则版本、库存版本**，快照随修订保存。
- 本地改动按**选项操作号**（seq）记录；断网只进本地日志，重连后以各自离线前修订为共同祖先做**按字段三方合并**：单方改动直接落版，双方选择不互相覆盖。
- 两人同时改同一字段且取值不同时，**双方版本都保留**为待裁决冲突；在冲突面板选择顾客版或门店版后生成裁决修订。
- 合并、裁决、失效重算各生成新修订号；修订列表（`#/revisions`）、三维预览浮层、分享页都显示当前修订与失效原因。

### 失效与重算

- 库存批次或依赖规则变化时，只让命中变化 SKU 的**受影响选项与报价失效**，未波及选项保持有效。
- 冲突未裁清、库存不足、规则/批次/基础价漂移时，报价标记失效且**不能占用库存**。
- 改选受影响选项或点击「失效重算」后，按最新基础价/规则/批次落新版本，报价恢复有效。

### 报价锁定单

- 锁定为原子操作：逐批次扣减（优先低价差批次），任一 SKU 不足整体回滚，不产生任何占用。
- 冲突 / 缺货 / 漂移 / 写入失败均落 failed 单且零占用；缺货补货或写入恢复后，失败批次可用**同一幂等令牌重试**。
- 同一令牌重复提交返回原锁定单，**重复提交不追加占用**；释放锁定单时库存退回批次。

### 分享链接

- 新链接（v2）携带修订号与配置快照；旧链接（v1，无修订号）打开时自动在服务端**补录为首版**（backfill，相同旧链接复用同一修订）。
- 分享页展示修订号、是否最新、冻结口径，以及相对当前库存/规则的失效原因。

## 原有功能

- Three.js 几何体程序化建模，支持拖拽旋转缩放与四种相机预设。
- 六组选项的依赖校验、实时价格与关键规格。

## 验证

`scripts/flow-check.ts` 为纯逻辑联调脚本（Node 下以 localStorage shim 跑 mock 服务端），覆盖三方合并、同字段双版本冲突、定向失效、锁定幂等/回滚/重试、旧链接补版等 32 项断言。
