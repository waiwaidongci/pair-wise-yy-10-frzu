# AeroStation 三维产品配置器

基于 Vue 3、TypeScript、Vite、Three.js、TresJS、Pinia、Tailwind CSS、Headless UI 和 Vue Router。

## 运行

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm build
```

## 已实现功能

- 由 Three.js 几何体程序化组成空气净化器模型，不依赖外部模型文件。
- 鼠标/触控拖拽旋转和缩放，移动端采用响应式布局。
- 颜色、材质、滤芯、续航、支架和控制环六组配置。
- 材质、滤芯、支架和电池选项包含真实依赖校验与自动修正。
- 价格及六个关键规格随配置实时更新。
- 主视角、正视、俯视和细节四种相机预设，切换使用逐帧平滑插值。
- 配置编码进分享链接，打开后还原为同一套选择。

## 配置修订 → 库存批次 → 报价锁定单联动

数据、判定、页面分在三处：

- **数据层** `src/data/configData.ts`：产品数据、冻结快照、带版本的依赖规则与库存批次、模拟服务端（快照/按字段合并/锁定/重试）、分享载荷类型。
- **判定层** `src/stores/configurator.ts`：每次打开先冻结基础价、依赖规则版本、库存版本；本地改动按选项操作号（opNo）记录；断网重连按字段合并，选择不互相覆盖。
- **页面层** `src/pages/` 与 `src/components/`：展示当前修订、失效原因、冲突裁清与报价锁定状态。

关键行为：

- **按字段合并**：仅本地改→采用本地；仅远程改→采用远程；双方改到同一值→不冲突；双方改到不同值→保留双方版本（冲突），裁清前不能锁定报价。
- **失效重算只圈定受影响项**：库存批次或依赖规则变化时，只让库存不足或被新规则触及的选项失效，其余选项与报价保持有效。
- **报价锁定守卫**：冲突未裁清、库存不足或写入失败时报价不占用库存；失败批次可重试；同一幂等键重复提交不追加占用。
- **旧链接补首版**：无修订号的旧分享链接打开时自动补成首版修订（rev-1）。
- **三处展示**：配置列表、三维预览角标、分享页均显示当前修订与失效原因。

配置页底部「演练控制台」可模拟门店远程改动、库存批次推进、依赖规则更新、写入失败与重新连接，用于验证上述联动流程。
